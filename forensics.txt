========================================
FORENSICS CTF CHEATSHEET
========================================

[GENERAL APPROACH]
1. Identify file type
2. Open / inspect file
3. Extract hidden data
4. Search for "flag"

========================================
📂 FILE IDENTIFICATION
========================================

file filename

- Tells real file type
- Useful if extension is fake

========================================
🔍 STRINGS (MOST IMPORTANT)
========================================

strings filename
strings filename | grep flag

- Extract readable text
- FIRST thing to try always

========================================
🖼️ IMAGE FORENSICS
========================================

[Check metadata]
exiftool image.jpg

[Extract hidden data]
binwalk image.jpg

[Manual check]
- Open in text editor
- Look at bottom of file

========================================
📦 BINWALK (HIDDEN FILES)
========================================

binwalk file
binwalk -e file

- Extract embedded files

========================================
🗜️ ZIP / ARCHIVES
========================================

unzip file.zip

[If password protected]
- Try common passwords
- Check inside hints

========================================
📄 STEGANOGRAPHY
========================================

[steghide]
steghide extract -sf image.jpg

[Common passwords]
password
1234
admin

========================================
🧾 TEXT FILES
========================================

cat file.txt
less file.txt

- Look for hidden text
- Check unusual spacing

========================================
🔢 ENCODING INSIDE FILES
========================================

- Base64

- Binary

→ Decode using crypto cheatsheet

========================================
🧠 PCAP (NETWORK FILES)
========================================

[Wireshark]

========================================
🗂️ PDF FORENSICS
========================================

strings file.pdf
binwalk file.pdf

- Hidden data inside

========================================
🧩 COMMON TRICKS
========================================

- Hidden at end of file
- Wrong file extension
- Encoded inside file
- Multiple layers

grep -i password filename
